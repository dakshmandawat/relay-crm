# Relay CRM

Relay CRM is a high-velocity sales management platform built to prevent pipeline leakage and revive ghosted deals through automated lead decay scoring, instant communication links, and smart priority queues.

## Core Features

* **Automated Lead Decay Scoring:** Automatically flags stalled deals with dynamic priority badges (`⚡ Urgent Follow-up`, `🔥 High Risk`).
* **Direct Outreach Hub:** One-click WhatsApp deep links with pre-filled context and direct phone dialing.
* **Smart Filter Queues:** Instant toggles for urgent tasks, high-risk deals, and active pipeline stages across Table and Kanban views.
* **Chronological Lead Activity:** Slide-over drawer tracking conversation history, stage progression, and custom notes.
